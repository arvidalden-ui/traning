Senaste 14 dagarna

Regler

  1. Logga varje set med vikt och reps.
  2. Värm upp med två till tre lättare set i passets första övning.
  3. Klarar du översta repstalet i alla set höjer du vikten med minsta möjliga steg nästa pass. Annars försöker du ta ett rep till.
  4. Sluta varje set 1–2 reps före max. Sista setet i benspark, lårcurl, flyes, sidolyft, curl och pushdown går till max.
  5. Vila 2–3 minuter i tunga övningar och 1–2 minuter i övriga.
  6. Sänk vikten på 2–3 sekunder och använd hela rörelsen.
  7. Lägg inte till pass eller set.
